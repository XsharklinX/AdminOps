# AdminOps 1.5.2

## Español
Se abre sin administrador para cualquier usuario: «Modo técnico» lo pide solo cuando hace falta. La barra del cohete siempre a mano, también con AdminOps cerrada. Arreglos de un clic: menú Inicio, iconos, copiar y pegar, PDF, ratón inalámbrico, Bloq Num y quitar la actualización que rompió algo. Notas con capturas y casillas, deshacer USB y energía, y errores de Windows explicados.

## English
Opens without admin rights for any user: «Technician mode» asks only when needed. The rocket bar is always at hand, even with AdminOps closed. One-click fixes: Start menu, icons, copy and paste, PDF, wireless mouse, Num Lock and removing the update that broke something. Notes with screenshots and checkboxes, undo for USB and power, and Windows errors explained.
